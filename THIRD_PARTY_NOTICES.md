# Attribution, licenses, and public edition boundary

The repository is a clean snapshot with a new Git history. It is derived from [Armour/Multiplayer-FPS](https://github.com/Armour/Multiplayer-FPS). Chong Guo's 2017 MIT copyright/license is preserved in `LICENSE`; public game-code modifications are MIT as well. The MIT license does not override the licenses of dependencies, fonts, or artwork.

## Excluded

- All original and current Mixamo characters, extracted character textures, animations, avatar-derived prefabs and controllers. See [Adobe's licensing FAQ](https://community.adobe.com/questions-696/mixamo-faq-licensing-royalties-ownership-eula-and-tos-589400?lang=en): project use and standalone redistribution of raw assets differ.
- Unity Standard Assets, original warehouse/legacy models, textures, materials, original audio not explicitly verified above, production scenes and player/effect prefabs.
- Production Outpost files, including the repainted legacy container texture; no assumption is made that the project's MIT license covers those source assets.
- Build output, credential files, TLS private keys/certificates, deployment state, editor user settings, and all previous Git history.

The original minimal controller in `Assets/Scripts/Input/` replaces the excluded Standard Assets dependency only in this public source edition. Other game files change their input namespace references accordingly. This edition is not the exact production asset project and does not claim to be immediately playable after cloning. Import Unity TMP essentials locally through the editor menu; generated package resources are not part of this repository.

Editor asset import/generation tools are source code only. A tool referring to a missing asset path neither supplies that asset nor grants permission to redistribute it. Obtain permitted assets yourself or implement replacements. Please do not contribute restricted raw asset packages.
